# super contador

projeto desenvolvido para praticar lógica de programação com javascript, utilizando estruturas de repetição para realizar uma contagem a partir de dois números informados pelo usuário.

# sobre o projeto

o projeto consiste em uma página interativa onde o usuário informa um número inicial e um número final. Ao clicar em "Contar Agora!", o sistema realiza a contagem e exibe os números na tela.

# tecnologias utilizadas

- html5
- css3
- javascript
  
# funcionalidades
- definição de um número inicial
- definição de um número final
- realização automática da contagem
- exibição dos números na página
- validação do preenchimento dos campos

praticar conceitos de javascript, como entrada de dados, conversão de valores, estruturas de repetição, condicionais e manipulação do conteúdo da página.
